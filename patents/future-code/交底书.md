# 一、发明名称
一种6G无线接入网智能体协同控制方法及系统

# 二、技术领域
本申请涉及第六代移动通信系统（6G）的无线接入网（RAN）智能体协作、无线资源管理和网络切片控制，具体涉及在多个智能体同时改变基站发射功率、切换策略、小区休眠状态或无线资源配额时，联合约束受影响小区并验证配置的网络效果。

# 三、现有技术的技术方案
在6G智能体无线接入网（Agentic RAN）中，节能、移动性、覆盖和切片保障智能体可分别依据终端（UE）测量和业务状态提出控制动作。3GPP Rel-20 的 SA2、SA5 和 CT3 分别研究6G系统架构、管理编排和AI协议。RAN3研究包括6G RAN架构、数据及AI/ML框架。相应资料见检索报告。

公开方案包括根据无线动作和观测指标建立智能体关系图并缓解冲突（WO2023213422A1），在策略部署前通过规则或数字孪生开展冲突评估（US20260107161A1），以及按切片性能阈值配置、激活和优化接入网资源（CN109495907B）。NETCONF也已有候选配置、配置锁及确认提交，设备管理可分别读取配置意图和实际运行状态。

# 四、现有技术的缺点及本申请要解决的技术问题
不同智能体写入不同小区或参数时仍可能经无线链路产生冲突。例如降低A小区功率会把部分用户推向B小区，B小区的切片智能体可能正准备使用相同的物理资源块（PRB）余量。分别评估两个动作会遗漏合计用量。即使联合评估已通过，排队和传输期间的负载变化及其他配置修改也可能使评估过期。设备接受命令、实际应用配置、用户指标达标是三个可观测事件。丢失回执后，重复提交或过早释放承接容量均可能使业务失去保障。

本申请要解决的技术问题是，在同一批无线动作的评估、资源预留、基站执行及业务验收之间保持受影响资源的一致性。执行侧以受影响对象的版本和测量为条件控制配置写入，并以各设备的实际生效记录及其后的网络测量决定验收和资源释放。

## 5.2 按无线关系确定影响范围
以直接配置对象为起点，在版本g的关系图中扩展同频邻区、迁移承接小区及共享池切片。干扰上界可按各发射源的线性功率变化量乘以测量所得的链路增益上界，在载波和时间重叠处求和，再与阈值比较。共享容量或预计承接用户的对象直接纳入。扩展到固定点后得到范围Γ。关键测量缺失或扩展超限时，扩大至具备数据和执行能力的协调域，仍缺证据则停止准入。

Γ记录配置写入对象、执行条件依赖的只读对象、需保护的指标，以及资源键和时间区间。资源键可由小区标识、载波或带宽部分、上下行方向和共享资源池标识组成。共享池下关联切片配额，按池总容量和各切片上下限分别检查。时间区间包括迁移准备、配置生效及验证所需保护期。两个动作在重叠区间内共享容量、写入同一对象或改变对方的前置条件时，由协调器联合处理。执行和核验沿用同一Γ及其版本。

## 5.3 联合评估和分区资源预留
评估器从Γ读取快照和账本版本r0。按资源键及重叠时段计算占用上界。基础占用取在用承诺与同口径负载预测上界的较大值，再加尚未计入的在途义务、候选新增量和保护裕量，合计不得超过容量。对需要迁移的用户，可按业务速率除以保守的单PRB可达速率，向上取整估算新增量。波束、覆盖和切换采用联合约束。对有顺序依赖的设备动作，逐一评估执行前缀。评估记录绑定模型和约束版本、阈值、快照及结果。

在Γ对应的分区及时间段上，协调器比较账本当前版本和r0。匹配时原子写入预留，生成结果版本r1及执行凭证，凭证关联本组动作及顺序、影响范围、相关分区的r1、策略代际e、设备期望配置版本向量、只读依赖版本、数据新鲜度和偏移上限、起止时间及评估摘要。竞争写入导致r0失配时，使用新账本重新评估。实施例由同一协调域的单一有效所有者通过事务完成该过程。跨域动作须先在各域持有预留，协调器在所有预留齐备后发布凭证。过程中失败时释放已确认未提交的预留。

同一耦合范围默认只允许一个动作组处于可执行状态。组内各步骤共用一份评估。只要分区义务及范围保持不变，步骤从待执行转为在用的记账状态不更新r1。增加、释放或改变相关资源义务则更新该分区版本，未执行步骤须复核或重评。相互独立的分区维持各自版本，其更新不撤销其他分区的有效凭证。

## 5.4 基站侧复核和快慢协同
每次下发前持久记录目标配置摘要、动作标识、步骤序号和待核实状态。设备侧执行网关在受控配置写入边界检查凭证有效期、账本分区版本和预留、拓扑和只读依赖版本、策略代际及设备期望版本。对数值状态x，在采样年龄满足上限时核验|x−x_eval|/s ≤ ε，其中s为正的量纲尺度，ε为偏移阈值。类别字段直接比较。遥测样本允许刷新，配置和资源依赖按其绑定的版本核对。超限或版本不符触发重新评估。

同步配置写入可由独占网关在受控临界区内完成。对延迟生效的接口，网关在提交前持有已验证的分区预留，设备在应用时核对本地有效凭证、代际、有效期和期望配置版本。撤销凭证须经设备确认，或等其在设备侧确定过期后才能将对应资源转给冲突动作。只支持异步排队且无法约束应用的接口应限于仿真或影子评估。历史已发请求则在结果核实前保持资源占用。组内生效回执推进期望配置版本，未登记的外部修改使未执行步骤失效。

慢速策略按代际设置资源上限和允许动作范围。基站侧快速调度在该范围内执行。切换代际时，设备须安装新代际并拒绝旧代际，协调器收到设备确认后才在同一资源上发放新代际凭证。失联时，设备在旧凭证有效期内遵循其边界，到期切入预置保护策略。紧急覆盖或安全保护可在本地抢占，但须更新本地版本并记录实际生效状态，供控制连接恢复时核实。即时无线状态仍可能继续变化，由现场保护约束。

## 5.5 生效核验、状态协调及补偿
网关或设备持久记录动作标识、配置摘要、代际、应用前后版本和实际生效时间。同标识同摘要返回已有状态，摘要不同则拒绝。超时后按原标识查询。明确未执行需要可验证的拒绝或取消记录，以及旧请求无法再生效的证据。参数值相同或未查到记录均不足以确认动作结果。未知动作继续占用相关资源，并暂停相互冲突的新动作。

对于多设备动作组，核验器确认所有要求步骤的身份和生效证据。设设备d的生效时间为t_d，时钟误差上界为δ_d，稳定等待期为Δ。核验窗口起点取max_d(t_d＋δ_d)＋Δ，按业务约束设定观察时长、最少样本数和有效测量覆盖。仅在完整观测窗内目标和受保护指标均达标时，转为验收通过。此时在用容量继续计入账本，保护性预留按约定释放。样本不足在上限内延长观察，届时仍缺测则保留未完成状态。

部分生效或指标越界时先查明未决请求并阻止旧凭证继续写入。协调器按最新的配置、终端位置和负载生成带新标识的补偿动作，并重新检查范围、预留和执行条件。旧动作的保留资源在核实无后续副作用或补偿完成后清理。若仍有在用配置，将相应义务转为在用承诺。紧急保护后的实际配置也按同一流程核实。

## 5.6 实施例
**实施例1 切片保障与功率控制。** A小区降功率后，边缘UE可能迁移到同载波的B小区。切片保障智能体拟同时增加B的切片配额。构造示例中，B池容量为100个PRB，每个调度时隙已承诺74个，另留6个保护裕量。接收迁入用户和配额增加分别需要12个PRB，合计为74＋6＋12＋12＝104，两个候选动作均单独可行但不能同时执行。将第二项减至8个后，合计为100。协调器复核前缀状态并先为B安排承接资源，再允许A降功率。若执行前B的负载预测升至78个PRB，按超过3个PRB的偏移上限拒绝原凭证，并按新负载重新评估。B的切片时延和A、B的边缘覆盖均进入验收窗口。

**实施例2 小区休眠与切换。** 节能智能体拟使A休眠，移动性智能体拟把用户切入A。影响范围同时覆盖A及其承接小区，两个动作时间重叠时互斥。休眠依次要求承接小区资源生效、用户迁移和覆盖核验。任一依赖失效即停发休眠条件提交。若迁移后链路中断，继续保留承接容量，查询原标识并读取终端当前服务小区。补偿依据当前承载关系决定是否恢复A、调整邻区资源或继续观测。

**实施例3 迟到指令与回执丢失。** 策略代际7的动作在传输中延迟。设备安装并确认代际8后，迟到动作被拒。代际8下的一个动作已生效，协调器丢失回执。按原标识取得动作摘要、实际生效时间和版本后，进入指标观察。另一设备仍未知时，相关资源维持保留且观察窗口尚未开始。相互独立的分区可继续执行已通过复核的动作。

## 5.7 面向未来6G智能体的适配
本申请的逻辑消息包括能力发布、动作提议、评估、预留、条件提交、原动作查询和效果报告。提议携带目标及作用范围，条件提交携带凭证和步骤，查询携带原动作标识，效果报告携带设备生效证据及指标窗口。业务与网络智能体协作可在3GPP SA2研究的架构层对接。管理权限、闭环策略与结果可在SA5相关管理服务适配。跨实体消息的承载可与CT3协议研究适配。RAN3相关的测量、无线状态和节点控制由接入层提供。上述字段和流程为本申请的设计。

原型可用O-RAN管理侧、近实时控制器和基站侧适配器分层实现。可用动作取决于部署节点的服务模型、控制能力及实际配置的条件提交语义。大模型参与慢速意图和方案规划。基站快速调度使用本地配置及确定性校验。

# 六、本申请的关键点和欲保护点
主保护点为保持同一无线影响范围在联合评估、分区资源预留、设备侧条件执行和实测验收四个环节中的约束一致性。下列权利要求供技术交底和后续撰写使用。

**权利要求1。** 一种6G无线接入网智能体协同控制方法，包括下列步骤。
（1）获取带采样时间的终端无线测量、无线资源用量及切片约束，接收至少两个网络智能体的无线控制动作，按小区干扰、用户承接或切片资源共享关系确定动作组的影响范围，所述范围包含直接配置目标以外的受影响无线对象，以及资源键和作用时段。
（2）联合评估候选动作与所述范围内既有资源义务，确认满足容量和受保护业务约束，按评估所用的分区账本版本比较并写入所述资源键与时段对应的预留，生成绑定所述影响范围、结果分区版本、设备期望配置版本、策略代际和数据有效条件的执行凭证。
（3）由设备侧执行网关在应用配置时核验所述凭证及当前分区账本版本、设备配置版本、策略代际和无线状态有效条件，满足时按所绑定的动作标识及配置执行，失配时拒绝并重新评估。
（4）按同一动作标识取得设备生效证据，以实际生效时间确定指标观测窗，核验所述影响范围内的网络指标。执行结果未知时保持相关资源义务并查询原动作。验收通过时结转在用资源，动作终止时按已核实的配置占用处理预留。

**权利要求2。** 一种6G无线接入网智能体协同控制系统，包括状态服务、无线动作协调器、联合评估器、设备侧执行网关及效果核验器，各模块协作执行权利要求1所述方法。

**权利要求3。** 一种电子设备，包含处理器、存储器及网络通信接口，处理器执行存储的指令时通过网络通信接口执行权利要求1所述方法。

**权利要求4。** 一种计算机可读存储介质，存储被处理器执行时实现权利要求1所述方法的程序。

**权利要求5。** 根据权利要求1所述的方法，按干扰变化上界、用户承接或共享池关系扩展所述影响范围，达到扩展上限或缺少关键测量时扩大至可核验协调域或拒绝准入。

**权利要求6。** 根据权利要求1所述的方法，对多设备动作组按照预定执行顺序逐一评估各执行前缀。按同组动作有效回执推进期望设备版本，外部修改使未执行步骤失效。

**权利要求7。** 根据权利要求1所述的方法，对重叠时段中的在用承诺、未决资源义务和候选新增量求和，与扣除保护裕量的容量比较，并对非可加的覆盖或波束约束执行联合检查。

**权利要求8。** 根据权利要求1所述的方法，由慢速策略按代际限定快速控制可用资源及动作。控制权转移时，设备确认新代际后才为同一资源发布相应新凭证。

**权利要求9。** 根据权利要求1所述的方法，在受控配置写入边界按采样年龄和归一化偏移核验无线状态，按绑定版本核验配置及依赖对象。

**权利要求10。** 根据权利要求1所述的方法，持久绑定动作标识和配置摘要，丢失回执时核对原标识对应的动作记录和配置版本。已提交动作的预留仅在核实终态且无未决副作用后释放或结转。

**权利要求11。** 根据权利要求1所述的方法，按各设备生效时间与时钟误差上界之和的最大值加稳定等待期确定观测窗，检查有效测量覆盖和样本量。

**权利要求12。** 根据权利要求6所述的方法，将小区休眠置于承接容量生效、用户迁移和覆盖核验之后。前序证据失效时停止后续控制，并依据当前服务小区和负载生成补偿动作。

**权利要求13。** 根据权利要求1所述的方法，按影响范围对应的相关分区核对账本版本，依组内执行结果更新记账状态并保留原资源义务。独立分区更新维持其他分区的凭证有效性。

# 七、与第三条中最接近的现有技术相比，本申请有何技术优点
相较于按监测关系缓解冲突的方案，本申请预留由候选动作实际影响的资源键及时间段，覆盖邻区承接容量。相较于部署前评估方案，执行网关对评估结果和基站当下条件做同域复核。完成验收还需要配置实际生效后的无线指标。局部分区版本允许无耦合对象继续运行，未决动作的预留阻断共享资源的重复承诺。上述效果依赖测量覆盖、模型误差边界和设备实施能力。

# 八、其他有助于理解本申请的技术资料
复现可采用图1至图3和5.6节的三种构造场景。对照组依次采用独立智能体、静态优先级冲突协调和同一预测器的部署前联合评估。固定拓扑、业务、种子及动作提议。故障包含评估后负载变化、旧代际迟到、部分生效、丢回执及测量缺失。记录SLA违反率、边缘用户吞吐、切换失败率、能耗、冲突动作生效率、重复调节次数及控制时延。5.6节的数字用于说明准入运算，实网和仿真性能待测。

# 九、本申请的侵权证据可获得性
公开接口说明可核查动作提议、条件提交、原动作查询和效果报告是否携带对应字段。经授权的联调日志可关联同一动作标识、受影响资源键、账本版本、设备版本、配置生效时间和网络指标窗口。可用构造测试核查版本不匹配时的拒绝、同标识查询和资源释放时点。仅凭吞吐变化或一次调用结果无法确认系统内部使用了分区预留或版本校验，内部特征需结合接口记录及其他可获得证据判断。
