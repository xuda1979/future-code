| 审阅意见 | V1.1处理 | 对应章节 |
|---|---|---|
| 关系图、数字孪生冲突评估、配置事务和回滚都有在先公开 | 核对NEC国际公开、Qualcomm部署前评估及NETCONF。主权项聚焦同一无线影响范围对预留、配置写入和网络验收的连续约束 | 交底书三、六，检索报告二、三 |
| 全局资源版本会撤销无关小区的动作 | 以资源键及时间区间作为分区范围，比较评估前版本并绑定预留后的版本。保留在用及结果未知的资源义务 | 交底书5.2至5.3，权利要求1、7、13 |
| 多设备联合评估可能漏掉局部生效造成的覆盖缺口 | 检查每个可执行前缀的容量、覆盖及切片约束。只用已验证的组内回执推进期望版本 | 交底书5.3至5.4，权利要求6、12 |
| 排队设备可能执行已过期指令 | 同步写入受控串行化。延迟生效由设备复核有效凭证、代际、有效期及期望配置版本。代际切换以设备确认作为新凭证的发放条件 | 交底书5.4，权利要求8、9 |
| 相同配置读回、丢失回执或少量样本会误判完成 | 按原标识核查回执。保留未知动作的资源义务。基于最晚生效时间和时钟误差计算观测窗，检查覆盖和样本量 | 交底书5.5，权利要求1、10、11 |

| 原先文稿的标题、栏目和版面与中国移动样例不符 | 比较5号与6号样例。以6号成套模板为准，重建封面、边距、字号、行距、中文编号九节和四节 | 两份Word文件和导出器 |

补充比对了3GPP SA2、SA5、CT3及RAN3的6G研究方向。可适配的智能体角色和消息见交底书5.7。检索报告列明规范研究进度、文献编号、相关权项和主要组合风险。

使用python-docx核对A4、页边距、段落样式、封面字段、标题层级、权利要求编号、附图数及链接。按LibreOffice预览逐页核对版面和中文文字。Word正文指定仿宋、交底书标题指定黑体。Linux预览分别使用Noto Serif CJK SC和Noto Sans CJK SC替代，实际分页会受阅读环境字体影响。
