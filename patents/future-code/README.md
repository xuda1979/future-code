# 6G无线接入网智能体协同控制专利材料

发明名称为《一种6G无线接入网智能体协同控制方法及系统》。发明人沿用许达、王飞，申报单位为中国移动研究院。

多个网络智能体可通过不同无线动作影响同一个邻区或切片资源池。方案按无线耦合确定影响范围，在同一范围内联合评估并取得资源预留，基站侧复核凭证后执行，再用配置生效证据和实际网络指标完成验收。若结果不明，保留受影响资源并查询原动作。
