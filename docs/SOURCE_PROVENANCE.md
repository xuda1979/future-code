# Source provenance

This repository contains an imported terminal-CLI source snapshot alongside
subsequent runtime, research, test and tooling changes. Repository history is
the record of those changes; a path alone does not establish authorship.

The previous README described the imported snapshot as another product's source,
attributed it to Future, and cited a publicly exposed package source map. Those
historical statements have not been independently verified by the current
runtime changes and do not constitute a license grant.

The product README documents the current Foundry/Swarm behavior and setup.
Replacing outdated project descriptions does not establish ownership of imported
code. Existing copyright, attribution and license notices in source files are
preserved. This change adds no repository-wide license and makes no claim that
commercial distribution rights have been established.

Before assigning distribution terms, inventory imported files and dependencies,
identify their actual rights holders and applicable licenses, and record the
basis for each retained component. Changes to branch protection and repository
licensing are separate from runtime feature work.
