四种内置 API 协议不代表支持所有云厂商的专有特性。密钥可选择加密存储、运行时隐藏输入或运行环境注入。签名许可证必须经供应商离线初始化发行者公钥后才能启用。客户端源码可被修改，不能将离线激活宣传为完全防破解。
