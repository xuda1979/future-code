# Commercial launch gate

Human review is mandatory. Machine-readable checklist state is advisory, not a legal opinion.

| Gate | Required independent evidence |
|---|---|
| Source rights | Imported source and contributor ownership audit and remediation |
| Dependency rights | SBOM, retained notices, and verified commercial redistribution terms |
| Security | Secure execution, secrets, authentication, resource isolation and threat model |
| Live evidence | Live model, held-out outcomes, independently frozen checks, credible full cost |
| Customer pilot | External customer acceptance under agreed success criteria |

The commercial branch intentionally has no blanket product license until source ownership and redistribution are resolved. Open-source clients can be patched to bypass entitlement checks, so enforce high-value services on controlled servers in later releases. Neither the self-reported REVIEWED flag nor passing tests authorizes sale, redistribution or production deployment.
