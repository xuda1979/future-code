\section{Diagnostic-Service Evaluation and Ablations}\label{sec:v8evaluation}
\subsection{RQ5: corrected service-equal protocol}\label{sec:v8service}
The diagnostic contract fixes semantic selections and answers independently
of tree positions. Q1 reports full status, Q2 localizes failures, Q3 lists
unfinished obligations, Q4 discloses coverage, Q5 replays a completed wave,
and Q6a/Q6b restrict status to the frozen unit/integration predicates. Failure
groups use stable test-file paths; these predicates and groupings do not
assert a classification of test adequacy. Coverage includes the actual
declared, executed and missing ID sets. Epoch is a completed-wave count;
foreign snapshots are rejected and older snapshots are rebuilt consistently.

The tree service applies the learned permutation to kernel positions and
uses maintained subtree capsules for status aggregation. The indexed ledger
reads per-check events through its persistent index. Neither service calls
the archived-record reference answer implementation. A separate oracle
compares both answers to that reference; equality between the services alone
is insufficient. All \VnineOracleMatches{} comparisons and
\VnineInvariantChecks{} layout-invariance checks agree. New regressions
include a deliberately shared query error, which the independent oracle
rejects, and older-snapshot queries after full completion.

Both services use bounded FIFO query caches, identical JSON-lines answer
framing and DEFLATE level six. Every page descriptor counts inside its byte
cap. Indivisible oversized fields are rejected; decoding verifies complete
reconstruction. The query workload includes Q3, seeded additional replay
waves, both original and learned layouts, and actual cold/warm query pairs.
It comprises \VnineStudyRows{} paired query rows across \VnineSetups{} matched
trajectory/layout traces. Each arm records \VnineCacheHits{} actual cache hits.
Arm order is seeded separately. This is a single local timing campaign over
the archived candidates, not evidence about independently selected live tasks.

Canonical serialized persistent-state totals are \VnineHactStorage{} bytes
for HACT and \VnineFlatStorage{} for flat across the matched traces. These
exclude duplicate query-cache objects and describe neither resident RAM nor
traffic. Local setup/maintenance elapsed totals are \VnineHactSetupSeconds{}
and \VnineFlatSetupSeconds{} seconds, respectively. Setup is recorded once
per trace, then allocated uniformly across that trace only for the arrival
model; it is not assigned solely to Q1. Logical update bytes remain a separate
resource measure. These local timings support descriptive accounting rather
than statistical claims about deployment latency.

Modeled arrival adds archived serial completion time, allocated setup,
measured query aggregation/encoding/decoding, and compressed bytes divided
by declared goodput. It excludes no setup stage and adds no storage footprint
to wire bytes. All entries are marked arithmetic. Under this particular
critical-path model, eliminating flat aggregation entirely could reduce
arrival time by at most \VnineAggregationMaxReduction\%. The observed-ratio
estimate is reported separately from this infinite-acceleration ceiling.
The common archived-checker term is relevant to arrival from candidate start;
it must be removed when studying response latency for a query issued after
checking has finished. Physical transfer, concurrency and production demand
remain unmeasured.

The direct-wave refinement is a time-budgeted heuristic, so its negative
outcome does not prove that no higher-order optimizer can improve the layout.
A proper tree-shape ablation must hold the learned order fixed. Fixed-order
training optimality also does not imply held-out optimality. Proposition~\ref{prop:pairwise}

the deployed compiler exploits beyond-pairwise structure.

\subsection{Audit scope and correction record}\label{sec:v8audit}
The historical audit's seventy consistency entries passed despite errors in
v8's prose. The revised independent path imports no service, optimizer or
codec implementation; it verifies input digests and regenerates the current
result macros, query table and signed ablation paragraph from committed JSON.
Tests corrupt generated percentages, interpretation text and study rows to
ensure rejection. The artifact retains the original v8 JSON and documents
its withdrawn service-cost interpretation. In particular, the old optimum-gap
percentage and DP-improvement interpretation are not used as current evidence.
The original Amdahl arithmetic yields only \VnineOldAmdahlCeiling\% maximum
speedup, with its own historical denominator. It is not combined with the
corrected timing campaign. Functional query/codec tests complement this
arithmetic audit; passing either is not third-party certification.
