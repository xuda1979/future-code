# HACT v11 claims and evidence

The current concise manuscript is `paper/journal.pdf`; `paper/main.pdf`
retains the historical analysis. All changes are prepared for author review.

| Supported claim | Evidence | Boundary |
|---|---|---|
| Pairwise population summaries can miss globally optimal packet trees for every fanout >=3 and affine positive-slot price | General proof; `theory_generalization.py`; 39 exact parameter cases | Persistent refresh model; constructed laws, not observed prevalence |
| The separation also holds for complete epochs with each check completed exactly once | `strict_partition_witness.py`; full analytic contraction/orbit proof; all 2,752 six-leaf trees checked independently | Three externally chosen windows; fanout >=6 and 16/11<H/S<28/17; not the CLI's six-check fixed8 flush |
| The information penalties are sharp for the specified pairwise-only interface | Exact minimax two-action reductions in both proofs | Other higher-order summaries may distinguish the constructed laws |
| Valid layouts preserve acceptance and root status | Conditional theorem; guard and identity/migration/conflict regression tests | Assumes trusted immutable checking and atomic local fencing; no attestation/test-adequacy guarantee |
| Bounded full-wave fitting is training-monotone | Integer rescoring; disjoint-subtree proof; independent small-tree tests | Restricted exactness requires exact DP; implementation uses float64; no held-out monotonicity guarantee |
| New upstream execution evidence includes six projects and 30 complete runs | Frozen source manifests, raw phases, origins/calls and normalization audit; 151,380 check executions | Six convenience-sampled release snapshots; sequential completion batching, correlated repeats |
| Primary cap32 saves 1.493% on Click and 0.177% on Jinja, with three ties | Immutable fitting receipts, held-out runs3-4, independent packet reconstruction | Five admitted projects; Packaging UNKNOWN; no population or higher-order causal claim |
| Prespecified cap64 saves 16.00-18.69% on four cases | Same-order/refinement controls and secondary frozen layouts | Secondary endpoint; not substituted for cap32 after seeing outcomes |
| Layout transfer can lose after the stopping/source pattern changes | Eleven frozen source transplants; seven priced comparisons: 2 wins, 3 ties, 2 losses | Three VOID, one resource UNKNOWN; newer release test contract; not eight certified natural bugs |
| Current tree service does not repay its costs for this demand | Four arms, three randomized repeats, all-wave ingestion; 5,040 independently reconstructed answer checks | Five local project cases; controlled consumer; fitting separate; no WAN/model inference |
| Equal answers produce equal wire bytes under the common codec | Composition property plus matched raw/wire/page signatures | Conformance, not evidence of bandwidth superiority |
| Dense ordering does not fit this campaign's large-registry budget | 26,948-check Packaging trace; one float64 matrix ~5.81GB before dict/heap overhead | Optimization and bounded service measurement UNKNOWN; all IDs retained |

`audit/check_v11_compiler.py` imports no HACT compiler, layout scorer or service
answer helper. It independently reconstructs costs, raw-normalized correspondence,
selection receipts, answer digests and source-transfer results. Deliberately
corrupted costs, verdicts and answers must fail. AI-agent independence reduces
shared implementation error; it is not human peer review.

The environment hash in original public reports covers Python/platform, not
the complete dependency state. Jinja's dependency repair and post-hoc inventory
are explicit in `public_checks/ENVIRONMENT_DEVIATION.json`. Comparative arms
consume identical retained records; broad environment equivalence is unclaimed.
