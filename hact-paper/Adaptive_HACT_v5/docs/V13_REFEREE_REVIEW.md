## Proof checks

1. Semantic coverage, not display interval identity, defines cancellation.
   For every complete epoch, cold plus refresh saving is exactly
   sum_G a_G(1+h_e(G)). No change is made to the all-check acceptance predicate.
2. A set of s checks needs ceil(s/w) hit waves. Each of q-h untouched waves
   contains a distinct complement check, so h >= q-(n-s). Also h <= min(s,q).
   These statements include full-registry and singleton boundary cases.
3. The one-sided union bound uses log(K/delta), with the catalogue frozen
   independently of calibration. Dependence among candidates and checks inside
   an epoch is allowed; dependence between calibration epochs is not covered.
4. TV uses sup-event distance (one half of L1), so its expectation penalty is
   rho times the paired range, not twice that amount. The same-support
   condition is needed both for the range and its lower-end clipping.
5. Positive expected horizon gain is h*E[d]-I. An installation already charged
   by an epoch cannot be charged again. CPU/fit time is not converted to bytes.
6. A population feature interface exactly identifies all paired expectations
   iff their functions lie in its affine span. Orthogonal signed measures
   supply the converse. This is a score-identification result; the separate
   global-optimum constructions establish optimizer insufficiency.

## Remaining top-journal concern

The current evidence favors maintained counters for the controlled fixed-group
queries, and the transfer campaign has 3 primary wins, 18 ties and 9 losses.
The new theorem is a principled abstention/adoption contract, not a new positive
real-service measurement. A convincing empirical extension needs naturally
collected hierarchical requests and source changes from independent projects,
with consumer demand and admission rules fixed before outcomes, plus complete
fit/install/update/query/recovery ledgers. Repeating the same snapshots,
relabeling synthetic draws or choosing an easier baseline cannot establish it.

A theoretical-paper submission may be considered on its mathematical merits,
but the scope-specific separations and the ordinary ingredients in the new
calibration result should be disclosed without a priority or acceptance claim.
A subject-matter reviewer should assess novelty against current batch-update,
adaptive hierarchy, verification-evidence and risk-calibration work.
